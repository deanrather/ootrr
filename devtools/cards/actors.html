Stand next to a pot, grass, tree or chest and read its id and OOTRR name
The overlay writes the id and name above every ticked actor in the game. Actors with no id (made while playing: drops, spawned enemies) cannot be labelled, only listed.

The hash and the id are the same number in two bases: hex is what the game and objmap show, decimal is what OOTRR's files and the location notes use. A dash means the actor is not a placed actor (made at run time: spawned enemies, drops, effects, Link), so it has no placement id.
